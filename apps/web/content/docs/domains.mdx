# Domains

A domain represents one website or property. Each domain gets its own AI agent, knowledge base, product catalog, and conversation history.

## Creating a Domain

1. Go to **Dashboard → Domains**
2. Click **Create Domain**
3. Enter:
   - **Name** — Display name (e.g., "Acme Support")
   - **Slug** — URL-friendly identifier (e.g., "acme")
   - **Description** — Brief description of the domain
4. Click **Create**

## Domain Settings

Each domain has:

### Embed Secret

A secret key that authorizes the widget. Found in **Dashboard → Domains → [Domain] → Settings → Embed secret**, with a copy button next to it.

:::warning
The secret is in the page HTML of your dashboard, and in the embed snippet on
your site. Treat it like a password — anyone with it can post to your agent.
:::

:::warning
Never commit your embed secret to public repositories. Use environment variables.
:::

### Agent

Each domain has a dedicated AI agent. Configure it in **Dashboard → Agents**.

### Knowledge Base

Upload documents, crawl websites, and add manual entries. Found in **Dashboard → Knowledge**.

### Products

Sync product catalogs from connected databases. Found in **Dashboard → Products**.

## Multiple Domains

You can create multiple domains for:

- **Different websites** — separate helpdesks for each site
- **Different environments** — staging and production
- **Different brands** — distinct personas per brand

Each domain is independent with its own:
- Agent and personality
- Knowledge base
- Product catalog
- Conversation history
- Booking settings

## Embedding the Widget

Once you have a domain, embed the widget:

```html
<script defer src="https://ziyarn.vercel.app/widget.js"></script>
<zy-widget
  data-slug="YOUR_DOMAIN_SLUG"
  data-secret="YOUR_EMBED_SECRET"
></zy-widget>
```

### Widget

Pick the look visitors see: the Classic chat bubble, or the Glow aurora panel.
Set in **Dashboard → Domains → [Domain] → Settings → Widget**. Your plan
decides which widgets you can choose — the Free plan includes the classic
widget only.

## Domain Limits

Every plan has a domain limit — see **Billing** for the full table. The limit is
enforced when you create a domain, and it applies to the whole account, not per
team.

To create more domains, upgrade your plan or contact support.

## Teams

A domain can be worked on by everyone in a team. See **Teams** for roles,
invites and seats.
