# Changelog

Track new features, improvements, and bug fixes.

## [Unreleased]

### Added
- Teams: create a team, invite people, set roles, manage seats, rename or delete a team
- Team roles — owner, admin, member and viewer — with admins managing members and owners managing admins
- Team invites are emailed, can be copied as a link, expire after 7 days, and hold their seat until accepted or revoked
- Plan-based widget allowance: the free plan includes the classic widget, paid plans include every widget
- Pricing page with per-plan feature lists, a full-width free card and Business marked as recommended
- Orders page with chat/DB filter tabs
- Collapsible knowledge pages list
- Escalation notification system (email, badge, tab title, toast, browser)
- `queryRows` driver method for paginated database queries
- `includeOrders` boolean on data source tables

### Changed
- Plan limits: Plus gets 200 AI credits, Business 1,000 and Enterprise 3,000; emails go 500 / 2,000 / 10,000; Enterprise drops to 50 domains
- Improved widget typing indicator (600ms minimum display)
- Widget markdown rendering improvements
- Conversation titles derived from first message

### Fixed
- Dropdown menus show the highlighted row in both themes
- Native select menus follow the theme, so their option lists are readable
- A domain whose plan no longer includes its widget falls back to the classic widget
- Widget mobile close button
- Widget footer layout
- Conversations page scroll behavior

- Improved product lookup performance
- Enhanced widget styling

### Fixed
- Product search accuracy
- Widget color configuration

- **Patch** (0.0.X): Bug fixes
