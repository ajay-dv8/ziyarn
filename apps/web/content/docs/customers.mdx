# Customers

Track customer interactions, view conversation history, and manage relationships.

## Customer List

Go to **Dashboard → Customers** to see all contacts:

| Column | Description |
|--------|-------------|
| Email | Customer's email address |
| Name | Customer's name (if provided) |
| Last Active | When they last interacted |
| Conversations | Number of conversations |
| Source | How they found you |

## Customer Details

Click a customer to see:

### Profile
- Email address
- Name
- Phone (if provided)
- Custom fields

### Conversation History
- All past conversations
- Messages sent and received
- Agent responses
- Escalation history

### Orders
- Purchase history
- Payment status
- Order details

## Customer Tracking

The widget automatically tracks:
- First visit
- Returning visits
- Conversation history
- Products viewed
- Bookings made

### Identifying Customers

Customers are identified by:
- Email address (if provided)
- Conversation context
- Browser session

### Anonymous Visitors

Visitors without email are tracked by session:
- Can still chat
- History is preserved
- Identified later if they provide email

## Search and Filter

### Search

Find customers by:
- Email address
- Name
- Conversation content

### Filter

Filter by:
- Last active date
- Number of conversations
- Source (chat, booking, etc.)
- Custom fields

## Export

Export customer data:
1. Go to **Dashboard → Customers**
2. Click **Export**
3. Choose format (CSV, JSON)
4. Download file

:::note
Export includes only data you have permission to access.
:::

## Best Practices

1. **Keep records updated** — Verify customer information
2. **Respond promptly** — Quick responses improve satisfaction
3. **Track preferences** — Note customer preferences
4. **Follow up** — Use campaigns to re-engage
5. **Respect privacy** — Only collect necessary data

## Privacy

Customer data is:
- Encrypted at rest
- Accessible only to authorized users
- Deletable on request
- Never sold to third parties
