# API Reference

The Ziyarn API lets you build custom integrations, manage resources programmatically, and extend the platform.

## Base URL

```
https://api.ziyarn.com/v1
```

## Authentication

All API requests require an API key:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
  https://api.ziyarn.com/v1/domains
```

### Getting an API Key

1. Go to **Dashboard → Settings → API Keys**
2. Click **Create API Key**
3. Copy the key (shown only once)

### Key Permissions

| Permission | Description |
|------------|-------------|
| `read` | Read access to resources |
| `write` | Create and update resources |
| `admin` | Full access including delete |

## Rate Limits

| Plan | Per Minute | Per Hour |
|------|------------|----------|
| Free | 60 | 600 |
| Pro | 100 | 1,000 |
| Enterprise | 1,000 | 10,000 |

Rate limit headers:

```
X-RateLimit-Limit: 100
X-RateLimit-Remaining: 95
X-RateLimit-Reset: 1642248000
```

## Endpoints

### Domains

#### List Domains

```http
GET /v1/domains
```

Response:

```json
{
  "domains": [
    {
      "id": "dom_abc123",
      "name": "Acme Support",
      "slug": "acme",
      "created_at": "2024-01-15T10:30:00Z"
    }
  ]
}
```

#### Get Domain

```http
GET /v1/domains/:id
```

#### Create Domain

```http
POST /v1/domains
```

```json
{
  "name": "New Domain",
  "slug": "new-domain",
  "description": "A new helpdesk domain"
}
```

## Error Handling

### Error Response Format

```json
{
  "error": {
    "code": "not_found",
    "message": "Domain not found",
    "details": {
      "domain_id": "dom_invalid"
    }
  }
}
```

### Error Codes

| Code | Status | Description |
|------|--------|-------------|
| `unauthorized` | 401 | Invalid or missing API key |
| `forbidden` | 403 | Insufficient permissions |
| `not_found` | 404 | Resource doesn't exist |
| `validation_error` | 400 | Invalid request body |
| `rate_limit_exceeded` | 429 | Too many requests |
| `internal_error` | 500 | Server error |

### Handling Errors

```typescript
try {
  const response = await fetch("https://api.ziyarn.com/v1/domains", {
    headers: { Authorization: `Bearer ${apiKey}` },
  });
  
  if (!response.ok) {
    const error = await response.json();
    console.error(`API Error: ${error.error.message}`);
    return;
  }
  
  const data = await response.json();
  // Handle success
} catch (error) {
  console.error("Network error:", error);
}
```

## SDKs

### JavaScript / TypeScript

```bash
npm install @ziyarn/sdk
```

```typescript
import { ZiyarnClient } from "@ziyarn/sdk";

const client = new ZiyarnClient({ apiKey: "your-key" });
const domains = await client.domains.list();
```

### Python

```bash
pip install ziyarn
```

```python
from ziyarn import ZiyarnClient

client = ZiyarnClient(api_key="your-key")
domains = client.domains.list()
```

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" \
```

## Best Practices

1. **Use API keys securely** — Never expose in client-side code
2. **Handle rate limits** — Implement exponential backoff
3. **Verify webhooks** — Check signatures for authenticity
4. **Cache responses** — Reduce API calls where possible
5. **Use pagination** — Don't fetch all records at once
