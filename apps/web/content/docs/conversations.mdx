# Conversations

View and manage all chat conversations from the dashboard.

## Conversation List

Go to **Dashboard → Conversations** to see all active and recent chats:

| Column | Description |
|--------|-------------|
| Customer | Visitor's name or email |
| Status | Active, waiting, resolved |
| Agent | Assigned agent |
| Last Message | Preview of last message |
| Time | When last message was sent |

## Conversation Status

| Status | Description |
|--------|-------------|
| Active | Currently in progress |
| Waiting | Waiting for response |
| Resolved | Conversation completed |
| Escalated | Transferred to human |

## Viewing a Conversation

Click a conversation to see:

### Messages
- Visitor messages (left side)
- Agent responses (right side)
- System messages (escalation notices)
- Timestamps for each message

### Context
- Customer profile
- Previous conversations
- Products discussed
- Actions taken

### Actions
- **Reply** — Send a message as the agent
- **Escalate** — Transfer to a human agent
- **Resolve** — Mark as resolved
- **Close** — Close the conversation

## Human Handoff

When the agent can't help:

1. Agent detects it can't answer
2. Agent asks for permission to escalate
3. Visitor agrees
4. Conversation is flagged for human review
5. Human agent picks up the conversation

### Escalation Triggers

Automatic escalation for:
- Billing disputes
- Technical issues beyond agent knowledge
- Complaints
- Request for human agent

### Manual Escalation

Agents can escalate manually:
- Type "Let me connect you with a human"
- Conversation is flagged
- Human agent is notified

## Notifications

### Dashboard Badge

Unread messages show a red badge on the Conversations icon.

### Tab Title

Browser tab shows unread count: `(3) Ziyarn`

### Toast Notifications

Real-time toast alerts for new messages.

### Browser Notifications

Desktop notifications (requires permission).

### Sound

Audio alert for new messages (3-note chime).

## Search and Filter

### Search

Find conversations by:
- Customer email/name
- Message content
- Product discussed

### Filter

Filter by:
- Status (active, waiting, resolved)
- Date range
- Agent assigned
- Escalation status

## Best Practices

1. **Monitor active chats** — Respond quickly
2. **Check escalation queue** — Don't leave customers waiting
3. **Review resolved conversations** — Ensure quality
4. **Use canned responses** — Speed up common replies
5. **Track metrics** — Response time, resolution rate

## Analytics

Track conversation metrics:
- Average response time
- Resolution rate
- Customer satisfaction
- Escalation rate
- Most common topics
